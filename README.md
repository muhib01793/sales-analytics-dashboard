# 📊 Sales Analytics Dashboard

A modern, responsive, and performance-focused Sales Analytics Dashboard built with React. This project provides an interactive overview of business performance, sales trends, order statistics, and revenue insights using a dataset of 5,000+ orders.

## 🚀 Overview

The Sales Analytics Dashboard helps businesses understand their sales performance through a clean and intuitive interface.

It transforms raw order data into meaningful insights, allowing users to monitor important business metrics and analyze sales trends efficiently.
